This is an estimate, not tax advice. Federal figures use 2026 IRS brackets and standard deductions (Rev. Proc. 2025‑32). State figures use each state's published 2026 rate structure but are simplified — they don't account for local/city income taxes, tax credits, itemized deductions, phase‑outs, or state‑specific quirks (e.g. California's SDI payroll tax, Washington's capital‑gains‑only tax). Head‑of‑household state brackets are approximated using each state's single‑filer brackets, since most states don't publish a separate HoH table.
