Practice Exam

Load a bank of multiple-choice questions and work through it in Study mode for instant feedback after every question, or Test mode for a real-exam feel with your score revealed at the end. Either way, you'll get a full answer review and a domain-by-domain breakdown when you finish.

Upload an exam ▸

Exam banks are JSON files shaped like this:

{
  "examTitle": "string (required)",
  "author": "string (optional)",
  "dateCreated": "YYYY-MM-DD (optional)",
  "domains": { "Domain Name": "25%" },
  "questions": [
    {
      "id": 1,
      "domain": "Domain Name",
      "type": "single" | "multiple",
      "question": "The question text?",
      "options": [
        { "letter": "A", "text": "First option" },
        { "letter": "B", "text": "Second option" }
      ],
      "correctAnswers": ["A"],
      "explanation": "Why A is correct (optional)",
      "timeSensitive": false
    }
  ]
}
  • Every question needs a unique id, a domain, and at least 2 options.
  • type: "single" needs exactly 1 correct answer; "multiple" needs 1 or more.
  • correctAnswers entries must match one of the option letters.

Validated on upload, then saved to the server for everyone to use.
